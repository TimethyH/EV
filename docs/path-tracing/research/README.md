# Path tracing research notes – index

All notes were written on **2026-11-18** (before M0). They are raw research with sources; the distilled tutor
reference is `../knowledge.md`, the decisions are in `../plan.md`. Precedence when sources disagree:
**`plan.md` > follow-up notes > original notes > report**.

The original notes and the report were written before two facts were known: development happens mainly on the
**AMD RX 9070 XT**, and the NVIDIA card is an **RTX 3070**. That changed the plan to one CUDA-style source built for
HIP and CUDA, OIDN as the first denoiser and a self-written NRC (decisions D12, D14, D15, D16).
